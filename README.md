# HelloPuppy · 안녕멍뭉

반려견과 보호자를 위한 산책·급여 인증, 커뮤니티, 동물병원 방문용 건강 요약 프로젝트입니다.

## 폴더 구조

```text
HelloPuppy/
├── frontend/                 # 정적 웹 프런트엔드
│   ├── index.html             # 홈 진입점
│   ├── auth.html              # 산책 인증
│   ├── feeding.html           # 급여 인증
│   ├── health.html            # 보호자 건강기록(PHR)·병원 공유·FHIR 내보내기
│   ├── vet-share.html         # 동물병원용 공유 기록 열람·진료기록 입력 (로그인 없음)
│   └── assets/                # CSS, JavaScript, 이미지
├── backend/                  # FastAPI 사진 판별 API와 모델 학습 코드
├── Dataset/                  # 제공 데이터셋 및 직접 준비할 활동 사진
├── design/                   # 앱 원본 로고·화면 기획 이미지
├── docs/archive/             # 이전 중복 프로젝트 메타데이터 보관
├── LICENSE
└── README.md
```

## 프런트엔드 실행

먼저 아래 백엔드 서버를 실행한 뒤 VS Code Live Server 같은 정적 웹 서버를 `frontend/` 폴더에 실행합니다. `index.html`에서 시작하고 `mypage.html` 또는 `account.html`에서 계정을 생성/로그인합니다. 페이지 및 정적 자산 경로는 `frontend/` 기준 상대 경로입니다.

홈의 **커뮤니티 산책 코스 지도**는 Leaflet, OpenStreetMap 타일, Photon 장소 검색을 사용해 별도 API 키 없이 동작합니다. 커뮤니티 글쓰기에서 장소를 검색해 결과를 선택하면 장소명과 좌표가 SQLite에 저장되어 공개 지도에 표시됩니다. 장소 선택은 선택 사항이며, 공유된 위치·게시글 내용은 로그인하지 않은 방문자도 볼 수 있으니 공개해도 괜찮은 장소만 선택하세요. 지도에는 OpenStreetMap 출처를 표시합니다. 무료 공개 타일/검색 서비스는 사용량 제한과 이용 정책이 있으므로 대규모/상용 서비스에서는 자체 호스팅 또는 별도 제공업체를 검토하세요. Google Maps는 장소 카드에서 길찾기 링크를 여는 데만 사용되며 API 키는 필요하지 않습니다.

지도 마커에는 해당 장소 공유 게시물에 첨부된 사진 썸네일과 내용이 함께 표시됩니다. 로그인 사용자는 장소마다 한 번 추천할 수 있으며 추천 수는 SQLite에 저장됩니다. 지도 게시물과 함께 장소 공유를 선택한 사진·글·좌표는 공개 지도 API를 통해 로그인하지 않은 방문자에게도 보이므로 개인정보가 드러나지 않는 게시물만 공유하세요.

## 건강기록과 동물병원 연계 (EMR/EHR)

국내 동물병원 EMR(인투벳, 이프렌즈, 플러스벳 등)은 업체마다 형식이 달라 병원 간 직접 연동하는 표준이 아직 없습니다. 그래서 안녕멍뭉은 **보호자가 기록을 보관하고 병원에 전달하는 방식(보호자 중개형 EHR)**을 씁니다.

- **기록 항목**: 수의사법 시행규칙 진료부 기재사항(품종·성별·특징·연령, 동물등록번호 등), SOAP 진료 기록, 소동물 문진 체크리스트, WSAVA 영양 평가를 참고했습니다. 구성은 기본 정보, 방문 전 문진표, 알레르기·복용 약·질환·수술/마취, 예방접종·기생충 예방, 식이, 진료·검사·체중 기록입니다.
- **병원 공유 링크**: 보호자가 병원마다 1시간~3일짜리 링크를 만듭니다. 권한은 `열람만` 또는 `열람 + 진료기록 입력` 중에서 고릅니다. 1번 병원 수의사가 링크로 진단·처방을 남기면, 2번 병원은 열람 링크로 그 기록까지 함께 확인합니다. 병원 입력 기록은 `병원 입력`으로 따로 표시되고, 열람 횟수가 기록되며, 언제든 취소할 수 있습니다.
- **표준 형식 내보내기**: 보호자와 병원 모두 HL7 FHIR R4 Bundle(JSON)을 내려받을 수 있습니다. 동물 정보는 `patient-animal` 확장으로, 체중은 LOINC 코드로, 질병명은 농식품부 권장 표준 코드(선택 입력)로 담습니다.

공유 링크는 `frontend/vet-share.html#token=...` 형식입니다. 로컬 개발 주소(127.0.0.1)는 다른 기기에서 열 수 없으므로, 실제 병원에서 시연하려면 프런트엔드와 API를 HTTPS로 배포해야 합니다.

## 백엔드 실행

Python 환경 구성, SQLite 데이터 저장, 계정 API, 활동 분류 학습 및 백엔드 실행 방법은 [backend/README.md](backend/README.md)를 참고하세요. 백엔드 명령은 저장소 루트에서 실행합니다. 기본 DB는 `backend/data/hellopuppy.sqlite3`에 생성됩니다.
